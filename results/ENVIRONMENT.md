Trace IDs random; worker trace sampling 1%. All durations/statuses are synthetic telemetry values, not measured application latencies. Drain polls every accepted batch; its HTTP/SQL authentication cost is included, making reported completion rates conservative. These tests do not measure sustained capacity or independent-host network behavior.

The Go demo separately served 3,000 HTTP requests at concurrency 16, generating 9,000 root/child span attempts. Agent memory is self-reported Linux Getrusage **peak** RSS and runtime heap allocation, including process startup high-water behavior; not an independent current-RSS measurement. The CPU value is the final interval's process CPU seconds / wall seconds, not an average/maximum across the benchmark. No host-wide CPU/RAM utilization or instrumented-vs-uninstrumented HTTP performance comparison was performed.
